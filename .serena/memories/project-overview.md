# Project overview
Minecraft resource pack providing JR Hokkaido-style home and concourse PIDS displays for MTR 4 with Joban Client Mod v2. Shared JS behavior is in `assets/jsblock/scripts/jrh_pids_common.js`; home and LCD layouts are in `jrh_pids_home_renderer.js` and `jrh_pids_lcd_renderer.js`; theme entrypoints are `jrh_like_pids*.js`. Presets and configurable inputs are in `assets/jsblock/joban_custom_resources.json`. JavaScript is plain JSBlock runtime code with no package manager or build. Syntax-check changed scripts using `env -u NODE_OPTIONS node --check <file>` and verify visuals in Minecraft after `F3 + T`. Use `git diff --ignore-space-at-eol` when reviewing because working files may use CRLF.
